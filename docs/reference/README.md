# 원문 자료 (대표님 소유)

대표님(임성민·마잘남) 본인 저작 전자책 2권의 원문과 추출 텍스트. 새 세션/다른 컴퓨터에서도
지식을 다시 다듬을 수 있도록 저장소에 보관한다(대표님 승인 — 본인 소유 자료).

| 파일 | 설명 |
|---|---|
| `전자책-무료-*.pdf` | 무료 전자책 "광고비 0원으로 고객이 먼저 연락오는 스레드 마케팅" |
| `전자책-유료-*.pdf` | 유료 전자책 "스레드 광고비 0원으로 100만원 벌기"(직종별 퍼널 등 심화) |
| `전자책-무료.txt` / `전자책-유료.txt` | 위 PDF의 추출 텍스트(지식 상수 편집용) |

이 원문에서 뽑은 실전 노하우는 코드 상수로 내장돼 있고, 실제 글/기획 생성에 쓰인다:
- `src/agents/threadPrompts.ts` → `THREAD_KNOWLEDGE`(무료), `PAID_THREAD_KNOWLEDGE`(유료), `ALGO_KNOWLEDGE`.
- 이 상수들을 blog·youtube(remix)·agency 프롬프트가 import해 공통으로 참고한다.

지식을 고치고 싶으면 원문(여기)을 근거로 위 상수를 수정하면 된다.
