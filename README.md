# 3인 AI 편집 심사위원회

컷 편집과 강조 포인트(자막 강조, 펀치인, 효과음, B-roll, 썸네일 각 등)를 포함한 유튜브 영상 편집안을
**기획 PD / 편집자 / 전략(그로스) 담당** 3개의 AI 에이전트가 각자 100점 만점으로 채점하고,
3인 평균 90점 이상이면 자동으로 통과시켜 실제 컷 편집을 적용해주는 프론트엔드 전용 도구입니다.

백엔드 서버가 없습니다. 모든 처리가 브라우저 안에서 이루어집니다.

## 동작 방식

1. **영상 업로드**: 브라우저 안에서만 미리보기(서버 전송 없음)
2. **기획안 + 스크립트/자막 입력**: `.srt`/`.vtt` 업로드 또는 텍스트 붙여넣기 (타임코드 권장)
3. **3인 AI 심사**: `기획/편집/전략` 세 역할의 Claude 에이전트가 각각 실제 유튜브 편집 실무
   체크리스트(오프닝 후킹, 컷 리듬, 패턴 인터럽트, 자막 디자인, 리텐션 커브 등, 역할별 5항목 x 20점)로
   채점 + 컷/강조 제안 + 리스크를 반환
4. **통과 판정**: 3인 평균 점수가 90점 이상이면 통과
5. **자동 편집 적용**: 통과 시 `ffmpeg.wasm`으로 브라우저에서 실제 컷 편집(불필요 구간 제거)과
   강조 자막 삽입을 적용해 결과 영상을 다운로드

## 필요한 것

- **Anthropic API 키** (`sk-ant-...`): 앱 상단에서 입력하면 브라우저 `localStorage`에만 저장되고,
  Claude API 호출도 브라우저에서 직접 이루어집니다(BYOK, dangerously-allow-browser). 키는 서버로
  전송되지 않지만, 공용 PC에서는 사용 후 삭제하세요.

## 기술 스택

- React + TypeScript + Vite
- Tailwind CSS
- `@anthropic-ai/sdk` (브라우저 직접 호출)
- `@ffmpeg/ffmpeg` (`ffmpeg.wasm`, 브라우저 내 실제 영상 컷 편집)
